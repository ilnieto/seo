# Prompts profesionales de keyword research

Usa esta skill cuando el usuario (docente o alumno del módulo SEO/SEM) pida prompts, plantillas o ayuda para usar la IA en keyword research.

## Principio clave: preguntar lo necesario, una sola vez

No entregues una plantilla genérica con corchetes. Pregunta por el contexto del proyecto una única vez en la conversación y reutilízalo en todas las tareas siguientes. Nunca vuelvas a preguntar un dato que el usuario ya haya dado.

## Tareas que cubre

1. Lluvia de ideas de semillas y variaciones.
2. Generación de preguntas y ángulos de contenido.
3. Agrupación de listas largas como primer borrador de mapa de contenidos.
4. Primer borrador del briefing de contenido.

No se usa la IA para volúmenes, posiciones ni dificultad: eso requiere herramientas como Semrush, Ahrefs, Search Console o Keyword Planner.

## Procedimiento

1. **Tarea.** Si no está claro cuál de las cuatro tareas necesita el usuario, pregunta cuál es.
2. **Datos del proyecto (una sola vez).** Si aún no los tienes, pregunta en este orden y solo lo que falte:
   - Negocio o proyecto (una frase).
   - Tipo de negocio: e-commerce, servicios locales, academia o formación, blog o medio, SaaS, otro.
   - Dominio o web (opcional).
   - Público objetivo (quién compra o se matricula).
   - Mercado: España, Latinoamérica u otro.
   Si el usuario ya los ha dado en la conversación, úsalos sin preguntar de nuevo. Si cambia de proyecto, pregunta solo entonces.
3. **Preguntas específicas de la tarea:**
   - Lluvia de ideas: palabra semilla.
   - Preguntas y ángulos: keyword principal y tipo de página (blog, categoría, producto, landing, FAQ).
   - Agrupar listas: pedir que pegue la lista, una keyword por línea.
   - Briefing: keyword principal, secundarias (opcional), intención (informacional, comercial, transaccional), objetivo de la página, competidores (opcional) y tono o extensión (opcional).
4. **Confirmación.** Resume en pocas líneas lo recogido y pregunta si hay que cambiar algo.
5. **Entrega.** Genera el prompt completo, con los datos del usuario ya insertados, y añade las reglas: no inventar volúmenes, marcar estimaciones y señalar [REVISAR] para datos a comprobar.
6. **Ajustes.** Si pide otro formato (ficha, diapositiva, página HTML), adáptalo. Si pide otra tarea sobre el mismo proyecto, vuelve al paso 3 sin repetir el paso 2.

## Estructura de los prompts generados

- Rol: especialista en keyword research para SEO en español.
- Contexto: negocio, tipo, web, público y mercado.
- Tarea concreta, con el número de elementos esperado.
- Reglas: sin volúmenes inventados, intención indicada, borrador marcado como tal.

## Consejo para el alumno

El contexto es lo que hace útil al prompt. Toda cifra que proponga la IA debe verificarse en una herramienta SEO antes de usarla con un cliente.
